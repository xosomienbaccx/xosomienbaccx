# Xổ Số Miền Bắc

Website vệ tinh hỗ trợ giới thiệu và điều hướng đến nền tảng **Xổ Số Miền Bắc** tại:

https://xosomienbac.cx/

## Giới thiệu

Xổ Số Miền Bắc cung cấp thông tin kết quả xổ số, dữ liệu lịch sử và các công cụ tra cứu dành cho người dùng quan tâm đến XSMB, XSMT và XSMN.

Nội dung tập trung vào:

- Kết quả XSMB theo ngày
- Kết quả XSMT và XSMN
- Dò vé số
- Sổ kết quả
- Sổ đầu đuôi
- Thống kê xổ số
- Dữ liệu lịch sử
- Tin tức và hướng dẫn tra cứu

## Mục đích repository

Repository này được xây dựng để:

1. Giới thiệu hệ thống Xổ Số Miền Bắc.
2. Tổng hợp các đường dẫn tra cứu quan trọng.
3. Xây dựng GitHub Pages cung cấp thông tin dễ truy cập.
4. Cập nhật tài liệu và nội dung liên quan đến kết quả, tra cứu và thống kê xổ số.
